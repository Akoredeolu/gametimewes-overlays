Gametimewes · Watchalong pack
Matchday scenes in the Rossoneri style. Set the Mode tweak to Neutral for non-Milan games: the red and black stripes become solid brand red and "Forza Milan" becomes "Watchalong". Teams, score, minute and lineups are Tweaks. No match footage is shown, so each live scene is webcam and chat around the scorebar. In OBS, add this file as a Browser Source at 1920×1080 with the scene id appended, e.g. ?scene=w-live.
